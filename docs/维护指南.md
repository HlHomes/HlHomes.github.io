# 个人主页维护指南

项目目录：`G:\实习资料\my_project`

线上地址：<https://hlhomes.github.io/>

本次变更：[2026 年 9 月更新说明](更新说明-2026-09.md)

本文按“改哪个文件 / 怎么改 / 怎么验证”组织，适用于当前版本。

## 0. 常用命令

```bash
npm ci            # 首次安装，使用已提交的依赖锁文件
npm run dev       # 开发预览：http://localhost:4321
npm run check     # 类型检查；修改 .ts / .astro 后运行
npm run build     # 生成 dist/，推送前运行
npm run preview   # 预览构建产物
```

要求 Node.js ≥ 22.12，推荐 24。PowerShell 限制 npm.ps1 时用 `npm.cmd run build` 等命令。Astro 开发服务如在后台运行，可用 `npx astro dev stop` 停止。

不要同时启动 `check` 和 `build`，两者都需要写 Astro 内容缓存，Windows 下可能出现文件占用。

## 2. 日常维护

### 2.1 改个人资料

编辑 `src/config.ts`：

- `PROFILE.name`：姓名。
- `PROFILE.tagline`：侧栏研究定位。
- `PROFILE.affiliations`：学校、当前单位，每项有 `zh` / `en`。
- `PROFILE.bio`：首页第一段正文；中文当前保留指定原文和 😊。
- `PROFILE.location`：所在地。
- `PROFILE.avatar`：头像路径，对应 `public/`。
- `SITE.description`：搜索结果摘要，研究方向变动时同步。
- `SOCIALS`：社交链接；`url: ''` 隐藏该项，邮箱必须带 `mailto:`。
- `SKILLS`：技能分组及标签。
- `HOME_LIMITS`：首页论文和文章的展示条数。

首页“联系我”按钮使用 `SOCIALS` 中的邮箱，没有邮箱时自动隐藏。

### 2.2 改教育经历

编辑 `src/data/education.yaml`，每条 `id` 唯一，按入学时间倒序排列。

```yaml
- id: swjtu-master
  school:
    zh: 西南交通大学
    en: Southwest Jiaotong University
  degree:
    zh: 硕士
    en: Master's
  major:
    zh: 人工智能
    en: Artificial Intelligence
  start: '2024-09'
  end: '2027-06'
```

当前只显示学校、专业（学位）、时间。课程、荣誉、排名和学校标签均不展示。即使向数据里补充旧版 `highlights` / `badge` 字段，当前组件也不会显示。

### 2.3 改实习与工作经历

编辑 `src/data/experience.yaml`。实习用 `kind: internship`，工作用 `kind: work`。

```yaml
- id: company-2027
  kind: work
  company:
    zh: 公司名称
    en: Company Name
  department:
    zh: 部门名称
    en: Department Name
  role:
    zh: 算法工程师
    en: Algorithm Engineer
  start: '2027-07'
  end: ''
```

`department` 为必填中英字段。只展示公司、部门、职位和时间，不展示地点、职责、业绩或项目细节。日期用引号包裹，`end: ''` 表示“至今”。

当前阶跃星辰的 `2026-05` 至 `2026-11` 按简历原文记录；如实际结束时间变化，修改此处。正式入职后增加一条 `kind: work` 即可自动显示工作经历，同时更新 `PROFILE.affiliations`。

### 2.4 发博客

在 `src/content/blog/zh/` 或 `en/` 新建 Markdown 文件，文件名成为网址。例：`reading-notes.md` → `/blog/reading-notes/`。

```yaml
---
title: 文章标题
description: 一句话摘要
pubDate: 2026-09-20
lang: zh
tags:
  - 图像恢复
translationKey: reading-notes
---
```

在 frontmatter 之后写 Markdown 正文。支持代码高亮、行内公式 `$...$` 和独立公式 `$$...$$`。

| 字段 | 说明 |
| --- | --- |
| `title` / `description` / `pubDate` / `lang` | 必填，语言必须与目录一致 |
| `tags` | 可选标签，不需要注册 |
| `draft: true` | 只在本地开发时可见，不发布 |
| `updatedDate` | 可选更新日期 |
| `translationKey` | 中英对应文章写相同值，切换语言可直达译文 |

只有一种语言也能发布，没有译文时切换语言会回到另一语言的博客列表。

### 2.5 维护论文与专利

编辑 `src/data/publications.yaml`：

```yaml
- id: unique-paper-id
  title: '论文完整标题'
  authors:
    - Lei He
  attribution:
    zh: 第一作者：贺磊
    en: 'First author: Lei He'
  venue: IEEE Transactions on Image Processing (TIP)
  year: 2026
  type: journal
  note:
    zh: 已录用，待刊
    en: Accepted, awaiting publication
  featured: true
  links: {}
```

- `type` 可用 `conference`、`journal`、`preprint`、`patent`。
- `featured: true` 才进入首页，完整列表页显示全部记录。
- `attribution` 可选。简历只确认本人作者角色时，用它显示“第一作者”或“第一发明人”，不冒充完整作者名单。取得完整名单后填写 `authors` 并删除 `attribution`。
- `authors` 中与 `PROFILE.authorAliases` 匹配的名字自动加粗。
- `note` 是状态徽章；录用、待刊、初审通过、授权应按实际状态填写。
- `links` 可填 `pdf`、`code`、`project`、`doi`、`bibtex`；没有链接写 `{}`。
- 按年份倒序，同一年论文优先于专利。
- 专利申请号目前写在 `venue`，不把“已过初审”改写成“已授权”。

简历没有给出标题的两篇中文核心论文、两项已授权专利和专著，暂不生成独立条目。资料补齐后再添加。

### 2.6 项目经历的隐藏与恢复

当前项目经历不出现在首页、导航或独立页面，站点地图也排除项目地址。源数据和组件保留在仓库中供以后恢复。

`/projects/` 自动回到 `/`，`/en/projects/` 自动回到 `/en/`。GitHub Pages 上由 Astro 生成 HTML 跳转页，并非服务器 HTTP 301 规则。

如果以后确实要恢复：

1. 将 `src/pages/projects.astro` 与 `src/pages/en/projects.astro` 从跳转页改回使用 `BaseLayout` 和 `ProjectsView` 的页面。
2. 在 `Sidebar.astro` 的 `navItems` 中加回 `nav.projects`。
3. 在 `astro.config.mjs` 的 sitemap 过滤器中允许 `/projects`。
4. 需要首页精选项目时，在 `HomeView.astro` 查询项目集合并渲染 `ProjectCard`，自行设置数量上限。
5. 更新 `src/data/projects.yaml`，运行检查、构建和页面预览。

### 2.7 换头像与图标

将照片放在 `public/avatar.jpg`，把 `PROFILE.avatar` 改为 `/avatar.jpg`。建议正方形、主体居中、压缩至 200 KB 左右。浏览器图标为 `public/favicon.svg`。目前保留原有字母头像。

## 3. 调整标签

技能标签修改 `SKILLS`，文章标签修改 frontmatter 的 `tags`，论文状态修改 `note`。无需另建标签注册表。标签目前用于展示，不会执行搜索筛选。

## 4. 调整首页与导航

首页板块顺序在 `HomeView.astro`，移动整个 `section` 和对应标题编号即可。章节导航链接位于同一文件的 `section-nav`，需与板块 `id` 对应。

主导航在 `Sidebar.astro` 的 `navItems`；中英名称在 `src/i18n/ui.ts`。只从导航删除链接不会停止生成页面，若要停止公开内容，还必须处理对应路由。

新增栏目通常需要：数据文件 → `src/content.config.ts` 集合与字段校验 → 共用视图组件 → 中英两份路由 → 文案词典 → 导航。修改后运行 `npm run check` 和 `npm run build`。

## 5. 外观、字体与动态效果

### 5.1 配色

编辑 `global.css` 的 `@theme` 和 `html.dark`，分别控制浅色、深色主题。主要变量：

| 变量 | 用途 |
| --- | --- |
| `--color-canvas` | 页面背景 |
| `--color-surface` | 标签与表面背景 |
| `--color-ink` | 正文 |
| `--color-subtle` | 辅助文字 |
| `--color-line` | 分隔线 |
| `--color-brand` | 蓝色强调 |
| `--color-brand-soft` | 浅色光晕 |

允许使用 OKLCH 或十六进制颜色；更换颜色后检查两种主题的文字对比度。

### 5.2 字体和字号

使用本机 Aptos / Trebuchet MS 与中文 PingFang SC / Microsoft YaHei 等字体，无外部字体请求。

- 桌面正文：`@layer base` 内 `html { font-size: 18px; }`。
- 手机正文：`@media (max-width: 639px)` 内为 `17px`。
- 首页简介：`.hero-bio`，桌面约 20–24px，手机约 19.5px。
- 标题字号：`@theme` 内的 `--text-xl` 等。
- 侧栏文字：`Sidebar.astro` 的字号类。

不要引入外部字体 CDN；自定义字体应放 `public/fonts/` 并本地引用，中文字体需要做子集化。

### 5.3 动画和交互

| 功能 | 实现 | 如何调整 |
| --- | --- | --- |
| 视觉球面 / 生成波浪 / 加速流线 | `ResearchField.astro` 的 Canvas | 修改 `draw()` 的三种模式 |
| 鼠标影响视觉球面 | 同一组件的 `pointermove` | 调整 `pointer` 的系数 |
| 动画总开关 | `SiteEffects.astro` | 右下角按钮，偏好存于 localStorage 的 `motion` |
| 页面滚动进度 | `SiteEffects.astro` | 顶部 `.reading-progress` |
| 章节定位与高亮 | `HomeView.astro` + `SiteEffects.astro` | 锚点与 `aria-current` |
| 滚动淡入 | `global.css` 的 `.reveal` | 修改 `reveal-rise` 和 `animation-range` |
| 背景光晕 | `.page-glow` | 调整渐变、透明度 |
| 深浅色主题 | `ThemeToggle.astro` + `BaseLayout.astro` | 偏好存于 `theme` |
| 回到顶部 | `SiteEffects.astro` | 使用 `#top` 原生锚点 |

Canvas 限制在约 30 帧/秒，并在离开视口、标签页进入后台或暂停动画时停止刷新。系统开启“减少动态效果”时自动停止动画，此时动画按钮不可开启。暂停按钮也会关闭 CSS 滚动淡入和平滑滚动。

禁用 JavaScript 时，正文、普通链接和静态研究图形仍可使用；Canvas 切换、主题切换等交互需要 JavaScript。浏览器禁止 localStorage 时，主题和动画当次切换仍可用，但无法跨页记忆。

若要默认暂停，将 `BaseLayout.astro` 中 motion 的默认值从 `'on'` 改为 `'off'`。不支持滚动驱动动画的浏览器直接显示内容。

### 5.4 布局

整体最大宽度在 `.site-shell { max-width: 1440px; }`。侧栏宽度在 `Sidebar.astro` 的 `lg:w-60`。桌面侧栏在 ≥1024px 时固定，≥1280px 时简介和点阵左右排列，更小屏幕上下排列。

文章阅读宽度仍由 `PostLayout.astro` 控制。调整后至少检查 390px 手机和 1440px 桌面，确认没有横向滚动。

## 6. 中英文案

全站大部分界面文字在 `src/i18n/ui.ts`。个人内容在 `config.ts` 和 YAML 中分别提供 `zh`、`en`。界面词典两种语言使用相同键。

研究方向文字为 `research.*`，动态按钮为 `motion.label`。文章切换语言使用 `translationKey`，不要手动拼接不确定的译文地址。

## 8. 故障排查

| 现象 | 排查方法 |
| --- | --- |
| Astro 提示 Node 不支持 | `node -v`，需 ≥22.12；`node -p process.execPath` 查看路径 |
| npm.ps1 无法执行 | PowerShell 下用 `npm.cmd` |
| YAML 校验失败 | 检查缩进、唯一 id、部门中英字段、日期引号 |
| 缓存文件 rename / EPERM | 停止并发的 build/check，再依次重跑；检查写入权限 |
| 有提交但网站没更新 | 检查对应提交的 Actions 是否完成，确认推送到 main |
| 样式或脚本 404 | 检查 Pages Source，以及 `astro.config.mjs` 的站点地址 |
| 主题切换刷新后未记住 | 浏览器可能禁止 localStorage |
| 动画不播放 | 检查系统减少动态效果、右下角开关、页面是否在后台 |
| 教育、工作板块没出现 | 检查集合是否有记录、kind 是否正确 |
| 项目网址跳回首页 | 当前版本的预期行为 |
| 论文未出现在首页 | 检查 featured 和 HOME_LIMITS.publications |
| 新博客看不见 | 检查 draft、lang 与目录、构建是否完成 |

## 9. 维护约定

- 保留 `package-lock.json`，部署依赖它复现依赖版本。
- 站点域名同时出现在 `astro.config.mjs` 和 `src/config.ts`，改域名时同步修改。
- 保留 `public/.nojekyll`，不要提交 `node_modules/`、`dist/` 或 `.astro/`。
- PDF / DOC 简历原件由 `.gitignore` 忽略，本次不提供原始简历下载。
- 不把原始简历手机号复制进网页，不编造论文标题、完整作者名单或发表状态。
- 保留 head 中主题初始化脚本的 `is:inline`，避免首屏主题闪烁。
- 保留减少动态效果支持，以及无 JavaScript 时的正文和静态图形。
